### Paste-once Prompt — blocked draft

> Use the files in `inputs/` to perform differential-expression analysis for `Cisplatin_IC50_CBD_IC50` versus `DMSO`. Use only the three replicates from each of those groups, with combination treatment as numerator and DMSO as denominator, and use `Group` as the only design term. Before fitting, retain genes for which at least one of the six selected samples has a raw count greater than 10. Use PyDESeq2 0.5.0 with `refit_cooks=True` and the standard `DeseqStats` contrast. A gene passes when `padj < 0.05`, `abs(log2FoldChange) > 0.5`, and `baseMean > 10`.
>
> Write all results under `output/`: `differential_expression.csv`, `summary.json`, `analysis.py`, and `report.md`. Do not use samples from other groups. Preserve unavailable adjusted p-values as null rather than converting them to zero. The report must be no more than 500 words and distinguish statistical association from causation.

This wording follows the q3 question's strict operators. It is not authorized for a formal scored run until the 677-versus-679 conflict is adjudicated.

### Strict output contract

`output/differential_expression.csv`:

- UTF-8 CSV with exactly these columns in this order: `gene_id,gene_name,baseMean,log2FoldChange,pvalue,padj,pass`.
- One unique row for every gene returned by the fitted six-sample DE model.
- `gene_id`: non-empty Ensembl gene ID; primary key.
- `gene_name`: mapped display name or empty when unavailable; it is not a key.
- `baseMean`, `log2FoldChange`, `pvalue`: finite decimal numbers.
- `padj`: finite decimal number in `[0,1]`, or an empty field for the model's unavailable/independent-filtered value.
- `pass`: lowercase `true` or `false`; unavailable `padj` implies `false`.
- Rows may be ordered by `gene_id`; row order is not scientifically scored.

`output/summary.json`:

```json
{
  "contrast_numerator": "Cisplatin_IC50_CBD_IC50",
  "contrast_denominator": "DMSO",
  "n_numerator": 3,
  "n_denominator": 3,
  "padj_operator": "<",
  "padj_threshold": 0.05,
  "abs_log2fc_operator": ">",
  "abs_log2fc_threshold": 0.5,
  "base_mean_operator": ">",
  "base_mean_threshold": 10,
  "n_genes_tested": 0,
  "n_genes_passing": 0
}
```

The two count values above are schema placeholders, not gold values. They must be non-negative integers computed from the submitted table.

`output/analysis.py`: UTF-8 Python; must read from `inputs/`, recreate the declared table and summary, and write only to `output/`. The grader performs static checks and may rerun it later in a separately approved isolated environment; the artifact grader never imports it.

`output/report.md`: UTF-8 Markdown, at most 500 words; state the contrast, sample counts, model/filter choices, passing count, important limitations, and no unsupported causal claim.
